1. Prompting Craft & Structured Outputs

The 4 Prompt Techniques:
  • System Prompts: Persistent behavioral contract across all turns.
  • XML Tags: Clean demarcations between instructions, examples, and data.
  • Few-shot Examples: Exact casing, format, and schema demonstration.
  • Output Constraints: Disallow conversational prose / preambles.
API Structured Outputs:
  • Constrained decoding guarantees schema conformance at generation time.
  • First-call grammar compilation latency is cached for 24 hours.
  • Injected schema system prompt counts toward billable input tokens.
  • Cannot combine with assistant message prefilling.
// SYNTHESIS PART 2

2. Tool-Use & Schema Design

The Single User Turn Mandate:

When Claude executes multiple parallel tools in one assistant turn, all tool_result blocks MUST be bundled into a SINGLE user turn.

Error Reporting with is_error:

Always return is_error: True in tool_result when exceptions occur so Claude can adapt instead of crashing the agent.

tool_choice Spectrum:
  • "auto": Model decides between text response and tool calls.
  • "any": Forces model to invoke at least one tool.
  • {"type":"tool","name":"..."}: Forces exact named tool call.
strict: true:

Guarantees tool arguments match your JSON Schema with zero hallucinated keys.

// SYNTHESIS PART 3

3. Extended Thinking & Streaming

Extended Thinking Rules:
  • budget_tokens must be >= 1,024 tokens.
  • Temperature is locked to 1.0 (API error if altered).
  • max_tokens must exceed budget_tokens.
  • Never strip thinking blocks in multi-turn tool loops.
  • Treat redacted_thinking as an opaque pass-through block.
Streaming Protocol:
  • Buffer input_json_delta chunks until content_block_stop.
  • Final stop_reason arrives in message_delta event.
  • Never persist turns until message_stop is confirmed.
  • Discard unfinalized partial tool blocks if network resets mid-stream.
// SYNTHESIS PART 4

4. Context, Memory & Agent Loops

Context & Memory Hygiene:
  • Prompt Caching yields 90% discount on static prefixes (>=1024 tokens).
  • Never replay raw prior session transcripts in-context.
  • Compress history into structured XML summaries.
  • Use Subagents to isolate exploratory tool outputs from main thread.
Agent Loops & HITL:
  • Hard MAX_TURNS circuit breaker prevents runaway token spend.
  • Clean loop exit when stop_reason == "end_turn".
  • Place Human-in-the-Loop gates on all destructive or mutating actions.
  • Prefer deterministic workflows when execution path is known.
// SYNTHESIS PART 5

5. Batch Ingestion & Multimodal

Message Batches API:
  • 50% cost discount across input and output tokens.
  • 24-hour turnaround SLA for non-interactive workloads.
  • Track requests with unique custom_id values.
  • Individual request failures do not fail the entire batch.
Multimodal Support:
  • Native PDF document blocks with type: "document".
  • Supported image types: JPEG, PNG, GIF, WebP.
  • Use the Files API for persistent reusable reference documents.
