// PRODUCTION BOTTLENECK

The Multi-Turn Token Explosion

In interactive prototyping, conversations last 3 to 5 turns. In production agents, an autonomous loop can run 20+ turns with large tool payloads (DB schemas, file contents, API returns).

Quadratic Token Cost:

Every new turn re-sends the entire preceding message history as input tokens. A 20-turn agent with 4,000-token tool returns easily consumes 200,000+ billable input tokens!

The Four Engineering Fixes:

1) Truncation, 2) Rolling Compaction (Summarization), 3) Prompt Caching (90% discount on cache hits), 4) Subagent Handoffs.

# Mathematical Context Growth:
Turn 01: [System + Prompt] = 2k in
Turn 02: [T1 + Tool 1 (4k)] = 6k in
Turn 03: [T1 + T2 + Tool 2 (4k)] = 10k in
Turn 04: [T1..T3 + Tool 3 (4k)] = 14k in
...
Turn 20: [Accumulated History] = ~80k in

Total Billed Tokens = Sum(T1..T20) > 800,000 tokens!
With Prompt Caching = 90% discount on static prefixes!
// COMPACTION PATTERNS

Rolling Compaction vs Truncation

Naive Truncation (FIFO Drop)

Dropping the oldest turns when context exceeds a threshold (e.g. keep last 10 messages).

# Blind FIFO drops initial user requirements!
messages = messages[-10:] # Dangerous

Risk: Drops original system constraints or user goals established at turn 1.

Structured Compaction

Compress middle turns into a concise structured XML summary: <conversation_summary>.

[Turn 1 (Original User Prompt)]
[Structured State / Summary of Turns 2..15]
[Recent 4 Active Turns with Tool Results]

Maintains goal continuity without blowing the token budget.

// COST & LATENCY OPTIMIZATION

Prompt Caching (cache_control)

Anthropic's Prompt Caching allows you to designate up to 4 cache breakpoints in your prompt using cache_control: {"type": "ephemeral"}.

Cache Hit Benefits:
  • 90% cost reduction on cached prompt input tokens.
  • Up to 80% latency reduction for large prompts.
  • TTL: Cached for 5 minutes from last use (refreshed automatically).
Minimum Cache Threshold:

Requires at least 1,024 tokens for Sonnet/Opus (2,048 for Haiku).

# Placing a Cache Breakpoint in Python SDK
response = client.messages.create(
  model="claude-3-5-sonnet-20241022",
  max_tokens=1024,
  system=[
    {
      "type": "text",
      "text": large_enterprise_guidelines,
      "cache_control": {"type": "ephemeral"}
    }
  ],
  tools=tools_list,
  messages=messages
)
// MEMORY ARCHITECTURE

The Three Scopes of Agent Memory

Scope 1: Ephemeral Session

In-Context Turn History

Lives only for the lifetime of the single task. Cleared immediately once the task is marked completed or user logs out.

Scope 2: User-Scoped State

Key-Value Profile Store

Stores verified facts (e.g. preferred language, account ID, company size). Injected concisely in system prompt.

Scope 3: Semantic Archive

RAG / Vector Retrieval

Stores past resolutions, tickets, and document embeddings. Retrieved dynamically on-demand, never dumped raw into context!

// ARCHITECTURAL ISOLATION

Subagent Handoffs: Context Isolation

When an agent needs to perform deep multi-step exploration (e.g. searching 50 files or running 10 SQL queries), doing it in the main agent clutters the conversation with massive tool outputs.

Subagent Handoff Pattern:

The main orchestrator spins up a dedicated subagent with a clean context. The subagent performs 15 turns of exploratory tool use and returns only a 1-paragraph summary back to the orchestrator.

# Context Isolation in Action
# Main Agent Context: 1.2k tokens
Orchestrator: "Investigate database latency spike."

# Subagent Context: Isolated & Discarded
Subagent Turn 1..12: Run 8 SQL queries, check logs...
Subagent Final: "Root cause: Unindexed query on orders.user_id"

# Back to Main Agent: Zero context pollution!
Orchestrator receives concise root cause and advises user.

A multi-session customer service assistant needs to remember the user's preferred delivery address and language across multiple distinct sessions over months. Which pattern best implements this without inflating token costs?
A. Concatenate all past conversation session transcripts directly into the messages array.
B. Persist key user attributes in an external database and inject a concise profile block into the system prompt.

// CERTIFICATION CHEAT SHEET

Context & Memory Rules for CCDV-F Exam

1. Avoid Full Transcript Replay

Never append unbounded prior session message logs in-context. Use summaries or key-value storage.

2. Prompt Caching Breakpoints

Place cache_control: {"type": "ephemeral"} on static system prompts and tools for 90% cost savings.

3. Subagent Context Shields

Use subagents to isolate messy tool exploration from the main user-facing agent thread.

4. Compaction vs FIFO Truncation

Always retain original instructions and summarize middle dialogue; do not blindly truncate turn 1.
