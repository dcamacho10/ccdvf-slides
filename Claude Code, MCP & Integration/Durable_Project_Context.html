The 2,500-Line Memory Collapse

APEXCORP PRODUCTION INCIDENT REPORT

ApexCorp developers dumped every rule, architectural diagram, coding standard, and deployment step into a single monolithic 2,500-line CLAUDE.md file.

Due to prompt dilution, critical data isolation rules at the bottom of the file were ignored. Later, a delegated Explore subagent accidentally exposed customer PII because built-in explore subagents skip CLAUDE.md!

ERROR: Rule dilution and misconfigured subagent boundaries lead to catastrophic context loss.
# CLAUDE.md (ApexCorp Anti-Pattern) # 2,500+ lines of un-scoped instructions... ... Line 2410: DO NOT EVER READ /data/pii_records.json! ... // Execution Trace: $ claude "investigate customer retention metrics" [Agent] Spawning built-in 'Explore' subagent... [Explore Subagent] SKIPPED CLAUDE.md & git status! [Explore Subagent] Reading /data/pii_records.json directly... FATAL: PII leaked into conversation context!
// ROOT CAUSE ANALYSIS

Why Monolithic Context Fails

1. Context Dilution

CLAUDE.md is loaded on every turn. As it balloons in size, the model's probabilistic attention splits across thousands of irrelevant tokens, missing core constraints.

2. Probabilistic vs Deterministic Enforcement

Prompt instructions are suggestions. If an action must never happen (e.g. blocking PII reads or blocking drop table), it must be enforced by a deterministic hook, not a text note.

3. Subagent Context Boundaries

Subagents start with a clean slate. Built-in Explore and Plan subagents deliberately skip CLAUDE.md to stay fast and cost-effective.

The Architecture Fix

Separate responsibilities into 4 specialized mechanisms: CLAUDE.md, scoped rules files, lifecycle hooks, and configured subagents.

// CONTEXT TAXONOMY

Four Specialized Context Mechanisms

1. CLAUDE.md

Always-on, persistent memory for the session. Keep it lean (under 100 lines): build commands, testing scripts, and high-level project philosophy.

2. Rules Files

Files in .claude/rules/ scoped to specific paths using glob matchers. Only injected when touching matching files.

3. Hooks

Deterministic shell scripts bound to execution events (PreToolUse, PostToolUse). Exit code 2 blocks tool calls instantly.

4. Subagents

Isolated task delegates. Keeps large exploratory traces out of the main conversation, returning only concise summaries.

// SCOPED GUIDANCE

Scoped Rules in .claude/rules/

Path Scoping via Frontmatter

Rather than loading backend security rules during a frontend React CSS edit, rules files define paths globs in YAML frontmatter.

  • Prevents token waste in unrelated sessions.
  • Eliminates rule collisions across stacks.
  • Automatically injected by Claude Code when touching matching paths.
# .claude/rules/api-security.md --- description: API security and authentication standards paths: - "src/api/**/*.ts" - "services/**/routes.py" --- ## Authentication Enforcement - All endpoints must include `@require_auth` decorator - Validate tenant isolation parameter on every SQL query - Never log headers containing `Bearer` tokens
// LIFECYCLE ENFORCEMENT

PreToolUse & Exit Code 2 Blocking

Hook Lifecycle & Exit Codes

Hooks run shell commands at specific lifecycle triggers: PreToolUse, PostToolUse, UserPromptSubmit, Stop.

PreToolUse Exit Code 2:
Exiting with code 2 cancels the tool call before execution! Whatever is written to stderr is returned to Claude as feedback to adapt.

Exit code 0 permits execution. Any non-zero exit code other than 2 indicates hook runtime failure.

// .claude/settings.json Hook Configuration { "hooks": { "PreToolUse": [ { "matcher": "Bash", "command": "./scripts/guard_rail.sh" } ] } } # ./scripts/guard_rail.sh if echo "$TOOL_INPUT" | grep -q "rm -rf"; then echo "ERROR: rm -rf is strictly blocked by company policy." >&2 exit 2 # Blocks the tool call deterministically! fi exit 0

// ARCHITECTURAL MATRIX

Which Mechanism When?

Use CLAUDE.md For:

Global, always-on context needed for 90%+ of sessions (build command: npm run build, test command: pytest, project architecture summary).

Use Rules Files (.claude/rules/) For:

Domain-specific guidelines that only matter when editing matching directories (e.g. GraphQL schemas, SQL migration safety, React state patterns).

Use PreToolUse Hooks For:

Hard, non-negotiable boundaries where model compliance cannot be left to probabilistic prompting (blocking drop database, secrets validation, audit logging).

Use Subagents For:

High-token exploratory spikes (searching 50 log files, reading massive repos) so intermediate junk does not bloat the main conversation memory.

// CERTIFICATION CHEAT SHEET

Lesson 2 Master Rules for CCDV-F

1. CLAUDE.md Dilution Trap

Keep CLAUDE.md under 100 lines for universal essentials. Move domain logic to .claude/rules/.

2. Exit Code 2 for Tool Blocking

PreToolUse hooks block tool execution deterministically with exit code 2. Stderr provides model feedback.

3. Subagent Clean Slate

Subagents start with empty context. Explore and Plan subagents skip CLAUDE.md and git status.

4. Deterministic vs Probabilistic

Never rely on prompts or CLAUDE.md for hard security gates. Always enforce via settings deny rules or PreToolUse hooks.
