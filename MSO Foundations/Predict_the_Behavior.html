Foundation 01 // Sampling & Probability

Temperature Scaling & Determinism

Temperature = 0.0 (Classifier Mode) High Precision

Concentrates probability strictly on the highest-ranked tokens. Ideal for classification, entity extraction, and structured tasks.

Label "SPAM": 98.2%
Label "NOT_SPAM": 1.8%
High Temperature = 1.0 (Creative Mode) Spread Distribution

Flattens the probability distribution. Increases phrasing diversity, but reduces consistency on strict categorical labels.

Label "SPAM": 55.0%
Label "NOT_SPAM": 45.0%
CCDV-F EXAM TRAP: DETERMINISM MYTH

Temperature 0 does NOT guarantee 100% bit-level determinism! While it heavily concentrates probability, hardware-level non-determinism (floating point batching across GPU clusters) can still introduce occasional token variation. Never answer on the exam that temp 0 is 100% deterministic.

Foundation 02 // Structural Enforcement

Zero-Shot vs. Multi-Shot Structural Anchoring

ZERO-SHOT (Instruction Only) High Token Efficiency
// Prompt:
Extract status and user from log into JSON. Do not add markdown.

Susceptible to format drift. Even with strict instructions, the model may occasionally output markdown code blocks or free text.

MULTI-SHOT (2-3 Demonstration Pairs) Rigid Format Guarantee
// Example 1:
Input: 2026-03-01 [OK] User: Alice
Output: {"status": "OK", "user": "Alice"}
// Current Query: Input: ... Output:

Strongest in-context format enforcer. Works exceptionally well on low-cost tiers (Haiku) to match large model fidelity.

RULE OF THUMB: 1 or 2 worked examples beat 3 paragraphs of negative constraints every time.
Foundation 03 // API Execution Mode

Choosing the Right Request Shape

1. SYNCHRONOUS / STREAMING

Synchronous blocking is ideal for simple CLI scripts and short headless tasks. Streaming (SSE) is mandatory for live user interfaces.

SLA: Seconds // Pricing: Standard
2. ASYNC CONCURRENCY

Uses non-blocking event loops (`AsyncAnthropic`) to dispatch multiple parallel API requests without blocking web server workers.

SLA: Seconds // Standard Limits
3. MESSAGE BATCHES API

Designed for bulk offline jobs (evaluations, document ingestion). Processes within 24 hours in exchange for a **50% discount**.

SLA: 24h // 50% Token Discount
Exam Fact: For bulk tasks without live human users waiting, the Message Batches API cuts token costs in half.
Foundation 04 // Token Ceilings & Failure Modes

Context Window Ceiling & Error Handling

HTTP 400 Bad Request

Occurs **before generation starts** when the input prompt + history alone exceeds the model's total context limit budget.

Result: Request rejected immediately with 400 status.
stop_reason: model_context_window_exceeded

Occurs **during generation** when the model runs out of remaining context space while generating output tokens.

Result: Returns HTTP 200 with truncated partial output.
REMEDIATION: Always inspect `stop_reason` before attempting to parse JSON responses! If context window was exceeded, prompt pruning or conversation compaction is required.

Mission Debrief // CCDV-F Exam Day Checklist

Elite Summary: Do's & Don'ts

DO'S (Certified Practices)
  • Use Temperature = 0 for predictable classifiers, remembering that it minimizes but does not zero out GPU floating point variance.
  • Apply Multi-shot (2-3 examples) to guarantee rigid JSON structure when verbal rules fail to fix formatting drift.
  • Select the Message Batches API for bulk offline jobs (e.g. 50k docs) to slash costs by 50% and bypass interactive rate limits.
  • Implement history compaction or window sliding in long agent sessions to prevent model_context_window_exceeded.
DON'TS (Exam Pitfalls)
  • DO NOT assume temperature only changes response length or that temperature 0 is 100% bit-level deterministic across runs.
  • DO NOT confuse multi-shot with model fine-tuning. Demonstration pairs reside in ephemeral context and consume tokens on every call.
  • DO NOT use blocking synchronous calls or interactive streaming for overnight offline data pipelines.
  • DO NOT expect the context window to expand automatically or drop old history silently without application logic.
