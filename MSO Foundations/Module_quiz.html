CCDV-F CONCEPT #1 (QUESTION 1)

Sampling & Non-Determinism in LLMs

PROBABILITY DISTRIBUTIONS
Examing Trap (Pegadinha da Prova):
LLMs do not return guaranteed identical text strings across calls. The model samples each next token from a probability distribution.
DON'T: Assert exact text matches in unit tests.
assert response == "Classification: Positive"
DO: Assert properties, schema, or semantic intent.
assert "Positive" in response.meaning

CCDV-F CONCEPT #2 (QUESTION 2)

Model Choice vs Reasoning Mode (Extended Thinking)

INDEPENDENT LEVERS
LEVER 1: Model Choice

Determina qual membro da família Claude executa a chamada (ex: Claude 3.5 Sonnet, Claude 3.5 Haiku, Claude 3 Opus). Define velocidade base, intelligence tier e custo básico por token.

LEVER 2: Extended Thinking

Parâmetro **por chamada** (thinking: {type: "enabled", budget_tokens: ...}). Pode ser ativado ou desativado independentemente em qualquer modelo compatível.

CCDV-F CONCEPT #3 (QUESTION 3)

Prompt Optimization & Token Bloat

COST vs EFFICIENCY
CCDV-F Core Principle:

Adicione exemplos (Few-Shot) apenas quando o formato de saída (output shape) estiver incorreto ou a tarefa for complexa. Se o Zero-Shot já funciona perfeitamente, adicionar exemplos apenas desperdiça custo por token em todas as chamadas sem benefício perceptível.

TOKEN COST IMPACT CALCULATOR 100,000 API CALLS
Zero-Shot Prompt 150 tokens/call
15.0M Tokens $45.00 Est.
+3 Unnecessary Examples 1,200 tokens/call
120.0M Tokens (+800%) $360.00 Est.
WHEN TO USE FEW-SHOT:
  • Claude struggles with complex JSON schemas or specialized formatting.
  • Enforcing consistent tone/style across niche enterprise domain domain jargon.
WHEN NOT TO USE FEW-SHOT:
  • Short classification tasks returning correct answers in Zero-shot.
  • When token costs/latency must be strictly minimized.
CCDV-F CONCEPT #4 (QUESTION 4)

Message Batches API vs Synchronous Loops

OFFLINE WORKLOADS
Synchronous API Loop High Risk
  • Hits Rate Limits (HTTP 429 Too Many Requests).
  • Full 100% standard token cost per query.
  • Requires active thread execution and connection polling.
Message Batches API Optimal Offline
  • 50% Cost Discount on all tokens!
  • Bypasses standard API rate limits for massive scale.
  • Asynchronous processing with pollable batch ID status.

CCDV-F Elite Cheat Sheet & Exam Anchors

HIGH YIELD SUMMARY
1. Non-Determinism

Amostragem probabilística torna a geração não-determinística. Em testes automatizados, avalie propriedades/significado semântico, nunca igualdade estrita de string.

2. Model vs Extended Thinking

São seletores **independentes**. A escolha do modelo define a família/capacidade base; Extended Thinking é um parâmetro por chamada chaveável em modelos suportados.

3. Optimization & Few-Shot

Não adicione Few-Shot se o Zero-Shot já funciona. Exemplos aumentam custo e latência em cada chamada sem melhoria substancial de precisão.

4. Message Batches API

Para processamento offline de grande volume, troque latência por **50% de desconto em tokens** e eliminação de erros 429 de Rate Limits.
