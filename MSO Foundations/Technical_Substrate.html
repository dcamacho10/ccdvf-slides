CCDV-F EXAM CORE CONCEPT

SDK and Raw REST are functionally identical at the network layer. They hit the exact same HTTP REST endpoints and receive responses from the exact same models.

Structural Parity: The SDK does NOT have secret endpoints, higher priority queues, or exclusive model capabilities over cURL/REST calls. It is simply a convenience wrapper.
    /> Retries automatically handled by SDK on 429/5xx /> API Key managed via `x-api-key` header automatically /> Messages API sits directly on top of this HTTP foundation
Dica de Estudo: A prova testa se você entende que usar o SDK não muda o comportamento subjacente da API de REST.

SDK Convenience Layer vs Raw REST API

Official Anthropic Client
# Instanciação direta com retry automático e validação de chave
import anthropic
client = anthropic.Anthropic() # Usa ANTHROPIC_API_KEY por padrão

message = client.messages.create(
model="claude-3-5-sonnet-2000",
max_tokens=1024,
messages=[{"role": "user", "content": "Diagnose latency bug."}]
)
print(message.content[0].text)
// TypeScript nativo baseado em Promises (Sem necessidade de cliente Async separado)
import Anthropic from '@anthropic-ai/sdk';
const anthropic = new Anthropic();

async function main() {
const message = await anthropic.messages.create({
model: 'claude-3-5-sonnet-2000',
max_tokens: 1024,
messages: [{ role: 'user', content: 'Diagnose latency bug.' }],
});
console.log(message.content[0].text);
}
# Requisição manual cURL - exatamente o que o SDK monta

--header "anthropic-version: 2023-06-01" \
--header "content-type: application/json" \
--data '{
"model": "claude-3-5-sonnet-2000",
"max_tokens": 1024,

CCDV-F Exam Traps (Do's & Don'ts)
DO: Usar o SDK oficial Reduz boilerplate, lida com parses de JSON complexos e aplica Exponential Backoff em erros transitórios (429/5xx).
DON'T: Achar que REST e SDK operam diferente Pegadinha comum da prova: Afirmar que o SDK oferece endpoints mais rápidos. Falso! É apenas um wrapper HTTP.
WARNING: Header Obrigatório Chamadas REST puras EXIGEM o header anthropic-version: 2023-06-01. O SDK injeta isso automaticamente.

Módulo 04 / Padrões de Alta Volumetria

Async Concurrency vs. Message Batches API

Padrões de Alta Carga: Qual escolher?
Async Client (non-blocking) Em Tempo Real

Para requisições concorrentes onde a aplicação precisa continuar fazendo outro trabalho enquanto aguarda a API.

SDK Asymmetry Exam Alert:
  • Python: Exige a classe explícita AsyncAnthropic.
  • TypeScript: O cliente padrão Anthropic É nativamente baseado em Promises (Async). Não existe classe separada!
Message Batches API Até 24 Horas (Offline)

Para processamento em lote gigantesco (Evals, ETLs, Migrações). Submete em uma chamada, recebe ID e faz polling do status.

~50% Menor Custo por Token Até 24h Latência

Módulo 06 / Resumo de Elite

CCDV-F Key Takeaways & Incident Remediation

01
SDK vs REST Parity

O SDK é uma camada fina sobre o REST HTTP. Ambos acessam exatamente o mesmo endpoint, os mesmos modelos e possuem os mesmos limites.

02
Streaming (SSE) Behavior

Reduz tempo até o primeiro token (TTFT). O servidor envia eventos em pedaços e o cliente reconfigura os fragmentos em tempo real.

03
Async SDK Asymmetry

Python requer classe explícita AsyncAnthropic. TypeScript é nativamente Promise-based sem classe async dedicada.

04
Message Batches API

Para tarefas offline/em lote. Latência de até 24 horas em troca de ~50% de redução no custo por token. Funciona via polling por Batch ID.
