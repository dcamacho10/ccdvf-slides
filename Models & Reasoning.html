The Latency & Budget Disruption

/var/log/omnicorp/ai-gateway.log HTTP 400 & LATENCY CRITICAL

[2026-11-02T00:12:01Z] Request payload dispatched to latest model tier...

CRITICAL ERROR: API responded with HTTP 400 Bad Request!
Message: "Unrecognized request parameter: 'budget_tokens'. Thinking budget is deprecated on current model generation. Use adaptive thinking with 'effort' control."

[2026-11-02T00:12:05Z] Secondary Incident: Call to Sonnet tier on intent classification taking 14,200ms!

WARNING: Adaptive reasoning enabled at high effort on simple lookup/classification task. Token expenditure +340%, SLA breached.

ANÁLISE DO INCIDENTE: O gateway cometeu dois erros clássicos de arquitetura:
  1. Enviou o parâmetro legado budget_tokens para um modelo de nova geração.
  2. Manteve o Reasoning Mode ativado para tarefas simples de lookup/classificação.

Erro #1: Legacy Budget Trap

Deprecated Parameter HTTP 400

Nas gerações mais recentes, budget_tokens NÃO é mais aceito e lança erro 400. A profundidade de raciocínio agora é ajustada via effort.

Erro #2: Unnecessary Thinking

Reasoning Wasted on Simple Tasks

Ativar reasoning em lookups e classificações gera gasto inútil de tokens e aumenta drasticamente a latência. O raciocínio deve ser reservado para problemas complexos de múltiplos passos.

Sua Missão: Corrigir a arquitetura do Gateway

Critical Exam Trap

`budget_tokens` Deprecation & HTTP 400 Trap

HIGH PROBABILITY EXAM QUESTION
ERRADO (DEPRECATED)

Legacy Parameter Usage

Usar o controle legados budget_tokens nas gerações mais recentes de modelos Claude.

// Request Payload (Python API)
response = client.messages.create(
model="claude-sonnet-latest",
max_tokens=4096,
thinking={"type": "enabled", "budget_tokens": 2048}, # ❌ ERRADO!
messages=[...]
)
RESULTADO EM PRODUÇÃO: Retorna HTTP 400 Error imediatamente! A requisição falha sem tentar reprocessar.
CORRETO (ADAPTIVE THINKING)

Modern Effort Setting

Ajustar a profundidade de raciocínio via parâmetro effort no modo adaptativo.

// Request Payload (Python API)
response = client.messages.create(
model="claude-sonnet-latest",
max_tokens=4096,
thinking={"type": "adaptive", "effort": "medium"}, # ✅ CORRETO!
messages=[...]
)
RESULTADO EM PRODUÇÃO: O modelo decide de forma autônoma quando e quanto raciocinar, sintonizado pelo effort escolhido (low, medium, high).
RESUMO PARA A PROVA: `budget_tokens` = Deprecated/HTTP 400 | `effort` = Parâmetro oficial de profundidade

EPISODE 02 CLEARED
1. SONNET IS DEFAULT

Comece workloads em produção sempre no Sonnet. Suba para Opus/Fable ou desça para Haiku apenas se guiado por resultados formais de Evals.

2. DUA ALAVANCAS

Escolha do modelo (tier) e ativação do raciocínio são independentes. O raciocínio é configurado por chamada via modo adaptativo com o parâmetro effort.

3. BUDGET_TOKENS TRAP

O parâmetro antigo budget_tokens foi descontinuado nos modelos atuais e retorna erro HTTP 400 Bad Request.

4. RACIOCÍNIO INTELIGENTE

Reasoning agrega valor em problemas complexos e multi-etapas, mas é desperdiçado em lookups simples e classificações rápidas.

5. THINKING OMISSION

Por padrão, o conteúdo dos blocos de pensamento é omitido no retorno. Solicite summarized display explicitamente se precisar exibi-los na interface.

6. BUILD TIME CONFIRMATION

Como a família Claude evolui continuamente, valide os identificadores exatos de modelos e padrões em platform.claude.com/docs.
